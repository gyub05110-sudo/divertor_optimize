# 전역 최적성 검증 기록 — 2026-10-24

## 결론과 범위

전체 물리 모델의 전역 최적해 증명은 확보하지 못했다. 현재 OMP 후보는 동일한 수치 목적함수에서 더 좋은 허용 이웃 형상이 있으므로 전역 최적해가 아니다. IMP는 cubic 기반의 명시된 유한 수치 모델에서 조건부 하한 인증을 얻었다. 이 결론을 연속 자기장·실제 플라즈마·quintic 보간에 일반화하지 않는다.

이번 작업은 기존 독립 IMP/OMP 열원, 무횡방향수송 모델, 여섯 설계 표면, 24개 계수, 기존 고정 경계에서 수행했다. PFR 방향 5 mm 연장과 원래 열계산 커널 수정은 수행하지 않았다. 기존 선택 형상도 교체하지 않았다.

## IMP: 하한과 달성 형상

각 폭 λ ∈ {1,2,3,5,10} mm에 대해 Qλ(c)는 기존 코드의 최대 열유속이다. 여기에는 샘플 경로의 열유속과 연속 경계 guard가 계산한 SOL 극한값이 포함된다. 목적함수는 다음과 같다.

    F(c) = max_λ [ Qλ(c) / Qλ(0) ]

24개 계수 전체 허용 상자(|ci| ≤ fl(0.1 + 1e−12) m)를 포함하는 바깥 방향 반올림 구간 계산으로 각 B-spline 노드의 변위를 감쌌다. 노드의 위치 계산 반올림을 포함한 다각형을 만들고, 인접 노드 다각형의 볼록껍질로 각 이동 벽 구간의 모든 가능한 위치를 감쌌다. 실제 생산 코드의 node_parameters와 de Boor 계산을 사용했다. 샘플 형상 몇 개로 전체 영역을 대체하지 않았다.

저장된 binary64 separatrix 경로와 고정 벽의 최초 교차를 정확한 유리수로 계산했다. 그 최초 교차까지의 경로 볼록껍질과 모든 이동 벽 구간의 포락선 사이에 엄밀히 양수인 분리축 간격을 확인했다. 부동소수점은 분리축 후보를 제안하는 데만 사용하며, 승인 판정은 Fraction의 정확한 유리수 연산이다.

따라서 이 저장 기하에서는 어떤 허용 계수도 고정 벽 최초 충돌을 앞에서 가릴 수 없다. 실제 evaluator가 그 정확한 교차 선택과 일치한다는 조건 아래, 고정 경계 root·법선·열원 정규화·극한 열유속 q*λ는 계수와 무관하다. cubic 고정 경계 root 탐색의 후보는 s=1 하나뿐임도 확인했다.

적어도 하나의 폭에서 q*λ = Qλ(0)이고, 실제로 1·2·3·5 mm 네 폭에서 값이 일치한다. 모든 허용 형상에 대해 Qλ(c) ≥ q*λ이므로:

    F(c) ≥ 1,   F(0) = 1,   따라서 min F = 1.

기준 형상 c=0은 생산 코드의 수치 제약을 통과한다. 이는 최소값에 대한 결론이며, 최소화 형상의 유일성을 주장하지 않는다.

| 설정 | 전체 범위 분리 통과 구간 수 | 보수적 분리 거리 하한 | 조건부 min F |
|---|---:|---:|---:|
| cubic 320 / 표면당 161 노드 | 960 | 3.1280739987e−8 m (31.28 nm) | 1 |
| cubic 2560 / 표면당 1281 노드 | 7,680 | 5.7410240532e−12 m (5.74 pm) | 1 |
| quintic 1280 / 표면당 641 노드 | 고정 벽 교차 전제 실패 | 해당 없음 | 미인증 |

두 cubic 설정 모두 전체 기하 증거의 재검사를 완료했다. fine 설정의 build 시간은 약 180.2초이며 이후 전체 replay가 추가로 실행됐다. 이는 최적화 탐색 시간이 아니다.

### 반드시 유지할 조건

- 수치적으로 생성된 경로, EFIT 보간 결과, 정규화 상수를 고정 입력으로 취급한다. 검증된 ODE 적분 오차 구간은 없다.
- GEOS의 전체 계수 영역에 대한 교차 선택 구현을 정식 검증한 것은 아니다. 정확한 저장 기하와 operational 선택의 일치가 조건이다.
- 형상·열원·기준 형상의 물리적 타당성은 별도 문제다. 수치적 feasible 판정을 연속 기하의 정리로 바꾸지 않는다.
- `--replay`는 저장된 기하 분리 증거만 재검사한다. 열유속, baseline feasibility, 전체 provenance, 조건부 최적성 정리 자체를 독립 인증하는 명령은 아니다.
- cubic 기본 해상도의 분리 하한은 약 31.28 nm, fine 해상도는 약 5.74 pm이다. 실제 연속 경로에 대한 오차보다 작을 수 있으므로 이 작은 여유를 물리적 강건성으로 해석하지 않는다. 해상도를 올려 얻은 양수 여유 자체가 연속 문제에서 양수라는 증거는 아니다.
- quintic 1280에서는 저장 경로가 고정 벽에 충돌하지 않고 `imp_sloped`에 충돌한다. 같은 고정 경계 증명 전제가 실패한다. 이것은 quintic 기준 형상이 비최적이라는 증명도 아니다.

모든 결과의 넓은 의미의 `global_optimum_proven`, `continuous_model_proven`, `experimental_validation`은 false로 유지한다. 제한된 정리의 상태는 별도 `conditional_frozen_model_global_minimum`에만 기록한다.

## OMP: 현재 후보에 대한 반례

보존된 OMP 후보의 0부터 세는 15번 계수에 −0.00001 m를 더했다. 이는 제어계수 변경이며 벽 전체를 10 μm 평행 이동한 것이 아니다. 같은 변경이 세 수치 설정 모두에서 기존 후보보다 낮은 목적함수를 보였다.

| 수치 설정 | 기존 후보 F | 변경 후보 F |
|---|---:|---:|
| cubic, 320 경로 | 0.6454575820499496 | 0.6454341942921014 |
| cubic, 2560 경로 | 0.6430561243338871 | 0.6430314217530947 |
| quintic, 1280 경로 | 0.6442538434825190 | 0.6442426898706576 |

세 설정에서 모두 feasible 및 독립 audit를 통과했다. 각 audit에는 전체 벽 최초 충돌 재계산, q 재계산, 고정 벽 좌표 불변, 전체 벽 기하, source 정규화와 열수지가 포함된다. JSON에 모든 계수와 제약 결과를 보존했다. −0.0001 m 변경은 기하 제약을 통과하지 못했으므로 반례로 사용하지 않았다.

이것은 명시된 부동소수점 수치 평가기에 대한 반례다. 기존 후보를 그 평가기의 전역 최적해로 선언할 수 없다. 새 이웃 후보의 전역 최적성도 증명하지 않았다. 2560 경로에서 감소율 차이는 약 0.00247026 percentage points이고, 이전 다중 해상도 차이보다 작다. 실제 플라즈마 성능 향상이나 제조 가능한 차이로 주장하지 않는다.

## 남은 증명 의무

연속 물리 모델의 인증에는 검증된 자기장 보간 및 field-line 적분 경계, 접촉/가림 전환을 포함한 최초 충돌 경계, 일관된 열유속 상하한, 형상 제약의 인증이 필요하다. OMP는 현재 후보가 반례로 탈락했으므로 더 나은 후보와 전체 계수 영역 하한이 일치하는지까지 확인해야 한다. 일반적인 Sobol/DE 재탐색이나 샘플 수 증가는 이 증명 의무를 대신하지 않는다. 실험 IR 자료도 제공되지 않아 실험 검증은 하지 않았다.

## 재현과 검토

프로젝트 루트에서 실행한다.

    python -X utf8 verification/certify_fixed_model.py --source IMP --level coarse
    python -X utf8 verification/certify_fixed_model.py --source IMP --level fine
    python -X utf8 verification/certify_fixed_model.py --source IMP --level quintic
    python -X utf8 verification/certify_fixed_model.py --challenge --level fine
    python -X utf8 verification/certify_fixed_model.py --replay input/D3D/optimized/global-certificate-20261024/IMP-cubic-320.json

각 IMP JSON은 전체 frozen 데이터, 기하 증거, 입력 해시, verifier 해시, 조건과 실패 원인을 포함한다. 코드와 입력의 실행 도중 변경은 거부한다. 문헌 검토 → 계획 및 사전 적대적 검토 → 테스트 → 구현 → 실제 계산 → 독립 코드·수학 검토 순서로 진행했다. 독립 검토에서 제기된 빈 표면의 공허한 성공, root 선택의 유일성, verifier 해시의 실행 시점 문제를 보완했다.

전체 verification 테스트 58개 통과. 복원된 기존 파일 898개 검증 통과. 보존된 생산 열계산 커널은 변경하지 않았다.
