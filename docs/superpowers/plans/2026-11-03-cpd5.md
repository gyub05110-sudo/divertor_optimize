# CPD_5 implementation plan

> Execute with subagent-driven-development for isolated geometry and review
> tasks; the coordinating agent owns equilibrium and campaign integration.

**Goal:** preserve CPD_5 inputs, freeze a declared FreeGS equilibrium, and run a
bounded three-hour fixed-power divertor search on branch CPD_5.

**Architecture:** additive cpd_optimization modules adapt independent material
contours and a FreeGS field to the existing transport kernels. Scientific inputs
and runtime products are separated; all large studies live on D:.

**Tech stack:** Python, NumPy/SciPy, Shapely, PyYAML, FreeGS, pytest, Git.

- [ ] Preserve input YAML and STEP hashes; push the named branch.
- [ ] Implement cpd_optimization/geometry.py and verification/test_cpd_geometry.py.
  Test circular arcs through all three points, metre conversion, closed contours,
  detached divertor and first material interception without artificial bridges.
  Plot and inspect all source component contours with node labels.
- [ ] Implement cpd_optimization/equilibrium.py and run_cpd_equilibrium.py.
  Test reference-field units, ampere-turn representation and serialized grid
  orientation against direct FreeGS queries. Derive Ip/Bt/betaN from the D3D
  parquet; fit pressure and solve coils against documented lower-null controls.
  Verify topology, LCFS/material clearance, beta/current residual and resolution.
- [ ] Adapt conservative first-hit/thermal transport to independent CPD solids.
  Test gap rays against analytic intersections and power lost/unresolved handling.
  Record the unmodified baseline before introducing candidate deformations.
- [ ] Implement a checkpointed deadline-bounded campaign with deterministic seeds,
  fixed equilibrium hashes and explicit baseline/candidate convergence comparisons.
  Optimize only divertor geometry; preserve anchors, solids and declared bounds.
- [ ] Run meaningful tests, independent review, and the three-hour campaign only
  after baseline acceptance. Commit source and compact evidence; push CPD_5 and
  report measured improvements, numerical limits, artifacts and elapsed times.

Never reuse D3D segment IDs or CPD-2 shared-node assumptions for CPD_5.
If the baseline/equilibrium cannot be qualified, save concrete diagnostics and
request the missing engineering choice rather than changing operating inputs.
