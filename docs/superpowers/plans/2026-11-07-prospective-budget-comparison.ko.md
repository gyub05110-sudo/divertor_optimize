# 새 평형과 예산에 맞는 정밀 대조군의 검증 계획

기준 커밋은 23164f6이며, 연구 근거와 실행 규칙은 [전향 시험 규칙](../../../results/nf-prospective-search-20261107/protocol.ko.md)에 둔다. 기존 평형 개발과 신규 입력 평가의 경계를 시험 전에 정한다.

1. 지난 600초 원이벤트에서 정밀 탐색의 초기 집단·국소·DE 단계 완료 수를 재집계한다. 기존 방법의 목표와 이번 지표를 AGENTS.md와 맞춘다.
2. 고정된 공개 자료에서 기사용 입력을 제외하고 열결과를 사용하지 않는 순서와 기하 검사로 세 입력을 고른다. 선택·탈락·출처를 저장한다.
3. 기존 SearchCase의 물리·탐색과 시간 기록을 재사용하는 실행기를 마련한다. D에 코드·프로토콜·입력을 고정한다. 개발용 여섯 정밀 실행에서 실제 적격 DE 발생과 피크로 대조군을 선택한다.
4. 선택 및 신규 입력을 봉인하고 18회 동일 시간 실행을 직렬 수행한다. 매 실행의 종료·후보·수지·초과 결과를 보호하고, 어긋난 원기록을 검출하는 검사로 600초와 1800초 선택을 재구성한다.
5. 채택 후보의 추가 네 수치 설정을 계산한다. 평형별 결과, 부호·실용적 차이, 면적 tradeoff와 실패, 비용 및 남은 과학적 범위를 한국어 보고서로 기록한다.
6. 독립 검산과 관련 회귀 검사를 실행하고, 결과·재현 절차·원기록 해시를 D에 보존한다.
