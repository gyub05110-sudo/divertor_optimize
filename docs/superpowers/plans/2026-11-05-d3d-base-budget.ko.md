# DIII-D 원형 기준 동일 예산 탐색 비교

제공된 실제 벽과 평형을 공통 기준으로 두고, 과거 해를 불러오지 않고 만든 설계 공간에서 고속 선별의 의사결정을 정밀 직접 탐색과 비교한다. 이 시험은 선별 단계의 효과를 분리한다. 기준 벽 유지 선택은 공학 제약을 만족하는 새 설계 찾기와 별도로 기록한다.

1. GitHub 브랜치에 이전 계산과 보고서를 먼저 보존하고 연구 원자료를 SHA-256과 함께 묶는다.
2. 1 MW, χ=0.3, λq=3 mm, DIII-D 1400 ms, OMP/IMP 각각 Rmin=20 mm, 세 시드 5161·7753·9923. 각 시드의 후보 12개는 열계산 전에 결정한다. 기하 제약만 이용한 무작위 목표의 투영과 검사를 사용한다. OMP에서는 네 변형면, IMP에서는 두 변형면과 공통 접선이 대상이다. 두 전략이 같은 순서와 시드를 공유한다. 원래 벽을 별도로 평가한다. 영벡터는 G1 조건 때문에 원형 벽과 다를 수 있다.
3. 한 열원에서 측정한 실비로 두 전략의 동일 200초를 재생한다. 기준 벽과 정밀 평가기 준비시간을 양쪽에, 320경로 평가기 준비시간은 고속 선별에만 포함한다. 각 후보의 기하 생성시간을 최초 접근 시까지 누적하여 청구한다. 고속 전략은 순차 4개씩 320경로로 평가한 다음 그 중 적격 최고 한 개를 cubic1280으로 판단한다. 직접 전략은 순차 후보를 cubic1280으로 평가한다. 기한을 넘겨서 끝난 후보는 성과에서 제외한다. 비용은 동일 장비의 실제 측정값으로 구성한 결정론적 재생이며 여러 프로세스를 동시에 돌린 스톱워치 대결과 구분한다. 두 전략이 같은 계산을 요구하면 동일한 실비를 사용한다.
4. 모든 후보도 독립적으로 cubic1280까지 계산해 해당 유한 집합의 최저값을 확인한다. 각 시드에서 200초 내 얻은 낮은 피크·A₂, 최초 기준 대비 5% 감소 달성시간, 개선 성공 여부, 유한 집합 최저 대비 초과율을 남긴다. 미도달·부적격·기준 벽 유지도 결과다. 과거 승자와 28점 격자의 재사용은 생성 후 별도 검사한다. FIREFLY와 실험 자료는 입력으로 읽지 않는다. 어떤 시드도 결과에 따라 교체하지 않는다.
5. 시간초과·무효 후보·제한된 정보만으로 선택하는 동작을 단위시험한 뒤 실제 계산한다. 코드와 프로토콜을 결과 보기 전에 커밋한다. 비교표·상세 후보·시드별 원자료를 브랜치에 보존한다.
