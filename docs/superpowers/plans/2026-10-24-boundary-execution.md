# 실행 기록

1. 문헌 조사 → 계획 작성 → 계획 자체 검토 → 적대적 검토를 코드 수정 전에 완료했다. 별도 문서에 근거와 반례를 기록했다.
2. 신규 경계 테스트 6개가 기능 부재로 실패함을 확인했다. 구현 후 6개 통과. 최대값 요약과 수렴 판정 테스트 2개도 실패를 먼저 확인한 뒤 수정했다.
3. 전체 46개 테스트 통과 및 복원 파일 898개 확인 후 본 탐색 시작. 원래 열계산 커널 파일은 변경하지 않았다.
4. 독립 코드 검토자는 계산식의 중대한 오류를 찾지 않았으며 재현성 해시 누락을 지적했다. 전체 13개 계산/실제입력 파일의 해시 검증과 실행 래퍼를 추가했다. 변경된 벽과 커널, 누락 해시를 거부하는 테스트 2개는 실패 후 통과했다. 검토자 재검토에서도 보완이 수용됐다.
5. IMP 탐색: 5,825 unique evaluations, geometry valid/feasible 2,034, 247.674 s. 두 DE는 동일한 기존 종료 조건에서 13/29세대에 종료(40세대는 상한). 목적함수 최선 1.0. cubic 320/640/1280/2560 및 quintic1280에서 모두 1.0, 전체벽 독립 검증 통과. 고정 strike 극한값 누락에 따른 개선 오판이 사라졌다.
6. OMP 탐색: 8,257 evaluations, geometry valid 2,160, feasible 1,911, 509.631 s. 계산 격자 최선 0.6483176873. 이전 후보를 새 영역/목적함수로 다시 평가한 값은 0.6454575820. 새 탐색 후보와 기존 후보 재평가를 별도 폴더에 보존하여 세부 검증한다. 병행한 검증 부하가 있어 이번 실행 시간을 과거와 직접 성능 비교하지 않는다.
7. 사용자에게 5 mm PFR 지지구간 허용 여부를 물었다. 사용자는 물리적 타당성을 질문했고, 형상 설계의 가능성과 실험·공학적 검증 한계를 설명했다. **이것을 영역 연장 승인으로 해석하지 않았다.** 모든 본 탐색은 buffer=0이다. 제안도만 작성했다.

현재 실행의 전체 의존성 sidecar는 탐색 진행 중 보완됐다. 캡처 이후 불변성은 검증하지만 캡처 이전의 모든 외부 수정을 소급 증명하지 않는다. 이후 실행은 `verification/run_continuous_search.py`로 시작 시점부터 기록한다.

8. 모든 세부 검증 완료: IMP ratio=1.0; OMP 새 탐색=0.6450462609; 이전 OMP 후보를 수정 모델에서 재평가=0.6430561243. 세 경우 모두 cubic 320/640/1280/2560, quintic1280의 형상·전체벽·수렴 검사 통과. IMP improvement_confirmed=false, 두 OMP는 true. 이전 OMP 후보를 유지했다. 전역 최적성 및 후보 간 미세 우열의 엄밀한 인증을 주장하지 않는다.
9. 전체 최종 테스트 48개 통과, 복원 파일 898개 재확인, 뷰어 JavaScript 구문 검사 및 브라우저의 IMP/OMP 결과 표시 확인. 브라우저에는 기존 OMP 후보의 수정 모델 재평가 결과를 표시했다. 결과 보고서·선택 JSON·과학 그림·뷰어 스크린샷은 continuous-boundary-20261024 폴더에 저장했다.
