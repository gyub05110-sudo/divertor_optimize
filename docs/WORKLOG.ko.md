# 작업 기록 — 2026-10-29 배포

## 유지하는 목표

기준 형상과 임의로 정한 유효 입력 조건에서 빠르게 divertor geometry optimization을 수행하고, 동일한 입력 전력에서 도착 열유속 peak를 낮춥니다. 미배분 전력을 줄이려고 실제 D3D 기준 형상을 먼저 바꾸지 않습니다. 측정값 일치를 별도 목표로 추가하지 않습니다.

## 완료한 작업

1. 원래 직접 자기장 매핑 코드, 기준 형상 및 과거 탐색 결과를 보존했습니다.
2. 연결 길이에 의존하는 broadening, 열전도·sheath 기준 상태와 횡방향 확산 폭을 추가해 비교했습니다.
3. 끊어진 표면별 분배에서 발생하는 누락 경로를 검토하고, 닫힌 연결 벽의 면적 좌표에 전력을 보존하여 전달하는 경계 분배 모델을 추가했습니다.
4. 토로이달 감김을 포함하는 연결 길이를 사용하면서 전체 도착 peak를 최적화했습니다.
5. IMP 8개/OMP 16개 계수로 각각의 영역만 변형하는 독립 실행을 구현했습니다. 반대 영역의 좌표가 변하지 않는지 별도로 검사했습니다.
6. RTX 3090에서 FP64 Gaussian 합산을 가속하고 CPU와 대조했습니다. 세 후보 평가의 중앙시간 기준 약 1.46배 가속, peak 차이 0, 분포 상대차 약 5e-16을 기록했습니다.
7. IMP 329개, OMP 331개 후보를 평가했습니다. 처음 찾은 최저 peak 후보는 보간 비율 허용치를 조금 초과하여 원본 그대로 남겼고, 각 12개 후보를 추가 선별하여 다른 후보에 전체 검증을 수행했습니다.
8. 검증 후 IMP는 21.201%, OMP는 50.280%의 peak 감소를 확인했습니다. 원자료, 형상 CSV/NPZ, 전력·열 상태·연결 길이·폭, 탐색 이력 및 그림을 저장했습니다.
