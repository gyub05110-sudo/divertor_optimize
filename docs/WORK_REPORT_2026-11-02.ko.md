## 1. 목표와 변경하지 않은 조건

목표는 주어진 기준 형상과 입력값으로 빠르게 divertor geometry optimization을 수행하고, 고정 입력 전력에서 도착 열유속을 분산하여 peak를 낮추는 것이다. 실험 측정값과의 일치는 목표나 통과 조건이 아니다. 실제 D3D 기준 형상은 비교 기준으로 보존했다. IMP와 OMP는 각각 독립 1 MW 실험이며 두 전력을 동시에 인가한 결합 최적화가 아니다.

대표 입력은 n=1e19 m⁻³, χ⊥=0.3 m²/s, λq=3 mm, γ=7, κ₀=2000이다. 기존 단방향 열전도·sheath 축약 수송과 전력 보존형 폐곡선 벽 Gaussian broadening을 사용했다. 평행 연결 길이는 toroidal 회전을 포함한다. 길이만 길어졌다는 이유로 임의의 전력 손실을 주거나, 미도착 전력을 재정규화하여 없애지 않는다.

새 대용량 자료, 실행 snapshot과 캐시는 D:/DivertorOptimization 아래에 두었다. 저장소에 이미 포함된 결과 파일은 재현성을 위해 유지한다. GitHub 공개가 D 드라이브의 모든 원시 로그를 백업한다는 뜻은 아니다.

## 3. 접선·곡률·개구부 모델

OMP 바닥 왼쪽 접합부에 위치와 접선 방향 연속인 G1 조건을 도입했다. IMP에는 가변 두 구간의 공통 접선과 고정 벽 연결을 포함한 3개 접합 조건을 적용했다. G2 곡률 연속까지 강제한 것은 아니다. 원래 고정 구조물의 다른 코너는 그대로다.

Rmin=20/50/100 mm는 제작 표준이 아니라 민감도 연구 설정이다. 절대 곡률 제한이므로 볼록·오목 방향을 모두 허용한다. IMP는 9개 변수, OMP는 16개 변수이며 재료 길이 상한, 구조물·LCFS·자기교차 제약을 유지했다. OMP 개구부는 고정 lip 끝점과 바닥 사이 최소 거리로 정의되며 기준 33.354336 mm 이상이다. 이는 유동/배기 성능의 직접 검증을 대신하지 않는다.

초기 OMP pilot의 당시 수치 검증 결과는 20/50/100 mm 순서로 1.446258/1.995853/3.111172 MW/m²였다. **이 초기 표를 최신 강화 판정에서 모두 유효한 개선으로 읽으면 안 된다.** 이후 전체 벽 검사의 차이가 발견되었고, 특히 낮은 OMP20 후보는 강화된 검사에서 탈락했다. 과거 보고서와 원본 수치는 역사적 기록으로 보존한다.

## 5. 발견한 문제와 수정

### 탐색과 최종 형상 검사 불일치

과거 OMP20 후보는 161점 벽에서는 통과했으나 chord tolerance 1e-7 m 벽에서는 R≈1.295 m, Z≈−1.42315 m 부근에 용기 고체 교차가 있었다. 이제 탐색·640 shortlist·최종 검증 모두 `full-wall-chord-1e-7.v2` 정책을 사용하며 열평가 전에 차단한다. 현재 검사도 유한 chord 근사이므로 연속 곡선의 엄밀한 비충돌 인증이라고 부르지 않는다.

### 이전 최선 후보 유실 위험

과거 최종화는 제한된 shortlist만 정밀 검증하고 과거 검증 후보를 반드시 포함하지 않았다. 그래서 긴 실행 결과가 이전 결과보다 나쁠 수 있었다. 이제 `qualified/<content-hash>/`에 manifest와 selected_refined를 함께 저장하고 해시·입력·정책을 확인한 완성 묶음만 선택한다. 중단된 `.pending` 묶음은 제외하며, 편의 포인터가 갱신되기 전에 중단되어도 완성 묶음을 복구한다. 기존 묶음은 덮어쓰지 않는다.

보호된 이전 후보는 일반 4개 최종 슬롯보다 우선 검증한다. 엄격한 반경에서 통과한 후보는 느슨한 반경에도 전달해 재검증한다. 과거 다른 형상 계열의 후보를 G1 계열로 옮길 때에는 seed로만 쓰고 이전 peak/qualified 지위를 승계하지 않는다. 현재 정책으로 형상 검사를 통과한 과거 OMP50 1.995853 후보도 이번 수정 과정에서 열수송을 다시 정밀 검증한 것은 아니다.

수정 당시 52개 회귀 테스트가 통과했다. 검사 중앙 시간은 네 저장 형상에서 약 2.4–3.6 ms, 추가 비용 약 0.3–1.5 ms였다. 이는 전체 최적화 속도 측정이 아니다. 이전 결과 26개와 snapshot 874개 해시를 보존했다. 상세: [정합성 보고서](../results/geometry-consistency-20261102/REPORT.ko.md).

## 6. 전역 최적성 경계 구현의 실제 범위

### 6.1 면적만 이용한 1변수 하한

정확한 유리수 spline 구간 계산으로 회전 표면적 상한 A_upper를 얻고, 전량 전달과 비음수 열유속 가정 아래 peak ≥ P/A_upper를 계산했다. 두 자식 구간을 모두 보존하며 표본값으로 구간을 제거하지 않는다. 저장 증명은 입력·분할·하한을 재계산해 확인한다.

IMP20 offset 1개 ±0.5 mm, 9개 표본 중 기존 후보만 수치 제약을 통과했다. 16회 이분할로 하한은 0.01348487644에서 0.01348572638 MW/m²로 상승했다. 수치 peak는 2.375044182였으나 인증된 후보 상한이 아니므로 이 차이를 인증 gap이라고 출력하지 않았다. 실행 14.6초, 당시 관련 테스트 62개 통과. [상세](../results/optimality-bounds-pilot-20261102/REPORT.ko.md).

### 6.2 고정 수송 분포의 연속 peak

방향성 Decimal 반올림과 무한 주기 Gaussian 꼬리 상한으로 공간 전체 peak를 감쌌다. 큰 확산 폭에는 Fourier 경계도 사용한다. 공간 분할은 전체 수신 영역을 덮으며 저장 인증서를 다시 계산할 수 있다.

IMP20 계수 3개를 각각 ±0.5 mm의 5단계로 함께 바꿨다. 125개 중 19개 통과, 92개 형상 제약 탈락, 14개 재료 길이 탈락이며 최선은 기존 후보였다.

| 경로 수 | 수치 peak | 고정 수송 분포 peak 검증 구간 MW/m² |
|---:|---:|---:|
| 320 | 2.375044182 | [2.375044, 2.376031] |
| 640 | 2.375136847 | [2.375136, 2.376119] |
| 1280 | 2.375134353 | [2.375134, 2.376132] |

표의 경계는 바깥쪽 반올림이다. 이는 계산된 donor 위치·폭·전력을 정확한 상수로 둔 분포에 대한 검증이다. 경로 추적과 열수송의 모든 오차를 포함하지 않는다. 이번에는 경로 수만 바꾸고 step 0.0005 m, target nodes 161, wall step 0.001 m, cubic을 유지했다. 과거 완전한 격자 검증과 설정이 달라 기존 최종 peak를 대체하지 않는다.

폭 ±1%, 위치 ±원래 폭의 1%라는 가정된 수송 집합도 시험했으며 peak 경계는 [2.31255146, 2.56626606]이었다. **실제 형상 구간이 이 집합에 들어간다는 증명이 없으므로 형상 최적값의 하한으로 사용하지 않았다.** `family_covers_geometry_box_proven=false`, `certified_geometry_optimality_gap=null`이다.

전체 실행 약 18.7분, 1280 분포 검증 약 500초였다. 76개 관련 테스트 및 실제 저장 320 인증서 재계산 통과. 독립 검토에서 끝점 c=A 거부를 수정했고, 90자리 비교 320개·정확 유리수 산술 비교 1,000개를 추가 확인했다. 상세: [수송 peak 보고서](../results/transport-peak-pilot-20261102/REPORT.ko.md).

## 8. 다음 작업과 판정 원칙

다음 과제는 형상 변수의 전체 구간에서 첫 충돌 위치·연결 길이·열수송 폭·수신 면적을 포함하는 구간을 계산하여 조건부 수송 경계를 실제 형상 문제와 연결하는 것이다. 첫 충돌면 전환, 접촉/접선 충돌, Bp 또는 target gradient가 0에 가까운 경우, finite path 밖으로 나가는 경우가 핵심 위험이다. 표본의 최솟값/최댓값이나 경험적 ±1%는 전체 구간의 보장이 아니다.

구간 산술 자체의 정확성, 입력 근사 모델의 정의, 연속 자기장선 적분의 오차, 형상 허용성, 전달 전력 보존, 최종 peak 경계가 각각 연결되어야 한다. 어느 하나가 미확정이면 그 상태와 범위를 보고하고 전역 최적성/gap을 인증하지 않는다. 현재까지의 작업은 전역 최적값이나 전역 최적 형상을 증명하지 않았다.
