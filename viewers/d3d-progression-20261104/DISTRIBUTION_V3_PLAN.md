## Reviewed method correction before final publication

Different receiving-cell widths make native step-field Linf compare different averaging supports: the unchanged baseline fails despite a stable underlying function. Therefore the final implementation uses saved continuous q samples, projected to their own cyclic physical wall with residual <=1e-7 m, and a piecewise-linear reconstruction on the exact union of sample/geometry knots. No peak alignment. Split at difference zero crossings before integrating absolute error. Continuous Linf/L1/A2 use the original 1%/0.5%/0.5% limits. Native-cell A2 remains a required check; step-field Linf is diagnostic. Reconstructed power must agree with unmodified native-cell power within0.1%; raw power must agree with assigned power within2e-12. This changes support comparison, not acceptance tolerances to fit candidates.

Tests include a smooth nonconstant function averaged on different grids, a secondary narrow peak below the unchanged global maximum, absolute-error zero crossings, and non-improvement combined with independent-audit failure. A reviewer independently reproduced baseline and rejected-candidate continuous Linf values and reviewed code/provenance. Final module is distribution_policy_v3_final.py; the prototype and its study are preserved.

Because all16 previously audited OMP20 candidates fail the new continuous-distribution test, complete the remaining3 archived OMP20 audits using fixed original inputs/GPU caches. Final selection thus covers all19 OMP20 stored milestones. OMP50's lowest1280 candidate passes, so no higher-peak candidates need full qualification.
