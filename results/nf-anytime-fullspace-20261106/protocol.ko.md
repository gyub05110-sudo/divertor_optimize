# 계산 전 고정: 실제 탐색의 시간별 성능과 최종 후보 수치 판정

연구 목적은 지정한 평형·운전 입력과 공학 제약에서 기준벽보다 피크를 낮추는 형상을 정확하고 빠르게 찾는 방법이다. FIREFLY 결과와 실측을 최적화 점수나 입력 보정에 사용하지 않는다. 이 단계는 동일 수송식 내 탐색 성능과 유한 수치 설정 민감도를 다룬다.

## 입력과 범위

- D:/DivertorOptimization/studies/unused-equilibrium-20261106의 사전 기하 검사를 통과해 시험했던 세 평형 deb842cf1e, fad1624516, 4d14a35fcb의 1400 ms를 그대로 사용한다. 이전 결과를 이미 보았으므로 이번 실험을 새로운 미사용 평형 선택으로 부르지 않는다. 형상 제안과 실제 실행은 새로 한다.
- 기존 DIII-D 물질벽, OMP 변형구간과 전체 벽 기하 제약을 유지한다. OMP 1 MW, n=1e19 m^-3, chi_perp=0.3 m²/s, lambda_q=3 mm, gamma=7, kappa0=2000, Rmin=20 mm를 고정한다. 원래 벽을 항상 유지 가능한 비교 기준으로 둔다.
- 세 시드는 20611,20627,20639이며 세 방법 각각 600초의 독립 프로세스를 한 번 실행한다. 시간 지점은 200,400,600초로 미리 정한다. 총 27개 실행, 명목 4.5시간이며 평가 하나의 종료까지 초과될 수 있다. 1800초, IMP, 다른 반경/운전점은 이번 단계 밖이다.

## 방법과 비용

- coarse_adaptive: 기존 SearchCase의 적응형 DE·좌표 개선·재시작을 cubic320에서 수행한다. 처음 보는 적격 저비용 후보 네 개가 모일 때마다 같은 묶음의 최저 피크 후보를 cubic1280으로 확인한다. 동률이면 먼저 평가한 후보다. 정밀 결과는 탐색 피드백에 넣지 않는다. 중간 시간 지점에서 미완성 묶음을 승격하지 않는다.
- fine_adaptive: 같은 SearchCase와 초기화 규칙을 cubic1280으로 수행한다. 정밀 점수가 적응 탐색에 피드백된다.
- random_fine: 기존 nf_base_budget.propose / nf_base_live.draw의 투영 무작위 형상 생성과 동일 기하 규칙을 사용해 cubic1280으로 평가한다. 앞선 12개 후보 상한을 제거한다. 열점수와 무관한 근접중복 배제 규칙은 유지한다.
- 적응 탐색 population=64, projected_seeds=12다. 과거 최적 형상 파일이 없는 staging root를 쓰며 초기화에서 이들 파일이 있으면 거부한다. 이후의 후보는 각 방법의 피드백에 따라 달라진다. 같은 시드가 적응 경로 전체의 같은 후보를 뜻하지 않는다.
- 세 방법 모두 기존 SearchCase.score를 사용하므로 첫 적격 GPU 결과에 동일 종류의 전체 q 배열·입사점·피크 CPU 대조가 포함된다. coarse_adaptive는 사용한 저비용/정밀 두 수준에서 이를 각각 지불한다. 검사 비용을 포함한 실행 성능을 보고하며 순수한 최적화 알고리즘 시간으로 바꾸어 부르지 않는다.
- 수치 튜플(method,count,step,nodes,wall_step): coarse=(cubic,320,0.0005,161,0.001), fine=(cubic,1280,0.000125,641,0.00025). 단위는 SI. 정확한 소프트웨어/장비/코드/입력 값은 frozen.json에 고정한다.
- 프로세스 실행 직전 부모 monotonic 시각부터 임포트·자기선/기준벽 준비·GPU 초기화·후보 생성/탈락·수송 계산·CPU 대조·실행 중 기록 비용을 센다. 각 방법은 전용 빈 D CUDA/CuPy 캐시를 사용한다. 장비 전체의 OS 파일 캐시를 지우지는 않는다. 방법 순서는 (case_index+seed_index) mod 3의 Latin rotation으로 교차하며 직렬 실행한다.
- 입력 확보/기하 사전 검사, 부모 해시·캐시폴더 준비, 최종 파일 직렬화·보고서와 사후 참조 계산은 시간 경쟁 밖의 비용으로 별도 보고한다. 같은 조건에서 준비 재사용이 가능한 운영 시간도 준비/평가 구간을 분리해 제시하되 준비비용을 없던 것으로 취급하지 않는다.

## 완료 시각과 실패

- 시간 t의 결과는 종료 시각 <=t인 적격 정밀 계산과 시간 내 준비한 기준벽 중 최소 피크다. 저비용 점수만으로 최종 결과를 채택하지 않는다. 동률이면 기존 후보를 유지한다.
- 600초 이후 종료된 점수도 상태·후보·시각과 함께 events.jsonl에 남긴다. 시한 내 선택이나 최초 개선 시각에는 넣지 않는다. 작업 중단은 완료한 계산의 경계에서 한다. 원본 수송 계산을 재정규화하거나 실패 후보를 교체하지 않는다.
- 프로세스가 1200초에도 종료되지 않으면 감독자가 중단하고 process_failed 및 시간 검열로 기록한다. 종료하지 못한 점수는 존재한다고 가정하지 않는다. 이미 기록된 event는 보존한다. 실패한 방법의 다른 대조 방법은 계속 실행한다.
- 최초 5% 감소가 관측되지 않으면 시간 초과/실패 원인과 우측 검열 상태를 기록한다. 600초에 성공했다고 대입하지 않는다. 같은 평형의 시드 반복을 독립 방전 수로 세지 않는다.

## 별도 유한 패널과 수치 판정

- 각 평형/시드에서 같은 기하 생성기의 적격 형상 24개를 열점수 없이 선택하고 목록·해시를 먼저 저장한다. 최대 기하 제안 6000회 안에 24개가 없으면 불완전 패널로 보고하며 시드를 교체하지 않는다. 원래 벽의 준비에는 수송 계산이 포함되지만 후보별 열결과로 패널을 선택하지 않는다.
- 패널 전부를 coarse/fine에서 계산한다. 원래 순서의 coarse 적격 후보를 네 개씩 묶고 완성된 묶음의 coarse 최저 후보를 fine으로 승격한다. 마지막 미완성 묶음은 승격하지 않는다. 따라서 정밀 요청 수 k=floor(coarse 적격 수/4)다. fine 부적격도 사용한 정밀 요청 수에 포함하며 기준벽 유지가 가능하다. 전수 정밀 참조 최저는 전체 24개 중 fine 적격 후보와 기준벽의 최소값이다. 이 집합에 대해서만 전수 최저 대비 손실을 주장한다.
- 같은 정밀 요청 수 k의 무작위 보조 비교는 같은 coarse 적격 모집단에서 중복 없이 k개를 균등 추출한 최저 피크의 정확한 기대값이다. fine 부적격은 개선하지 못한 결과로 처리한다. 이는 공통 저비용 검사 뒤의 평가 할당 비교이며 random_fine 실시간 방법이나 동일 시간 비교와 구별한다.
- 200/400/600초 최종 후보와 마지막 초과된 평가 후보를 고정한다. 각 선택 후보에 대해 같은 평형에서 시간 내 정밀 평가했던 별개 후보 중 native 피크가 가장 가까운 후보 하나도 진단 대상으로 고정한다(동률은 ID순). 후보 리스트와 선택 근거를 추가 수치 계산 전에 잠근다. 이 비교는 관측된 후보 집합 안의 가까운 피크를 다루며 형상 공간의 모든 인접 후보를 뜻하지 않는다.
- 기준벽과 고정 후보를 cubic640=(cubic,640,0.00025,321,0.0005), quintic640=(quintic,640,0.00025,321,0.0005), quintic1280=(quintic,1280,0.000125,641,0.00025)으로 다시 계산한다. native cubic1280 점수도 대조에 포함한다. 같은 설정의 기준 대비 비율과 설정 전체의 범위를 함께 표시한다.
- 모든 설정에서 기준보다 낮은지, 후보 피크 상한이 기준 피크 하한보다 낮은지, 비교 후보 범위가 겹치는지를 구분한다. 범위가 겹치면 미세 우열을 확정하지 않는다. 유한 설정 범위는 확률적 신뢰구간·연속체 오차상한·실험적 정확도가 아니다. A2 감소·부적격과 실패도 표에 남긴다. 특정 타일 q(s)의 1% 수렴을 이 지표로 대신 인증하지 않는다.
- 실제 적응 탐색의 최저 참조는 시간 내 관측한 정밀 후보들의 best-known일 뿐 전역 최적이 아니다. 별도 패널/수치 검증 비용을 실시간 속도에 포함한 것처럼 쓰지 않는다. 사후 스크립트는 계산 전에 별도 해시로 고정하고, 이미 고정한 선택·판정 규칙을 바꾸지 않는다.

원자료·코드 스냅샷·로그·캐시·그림은 D:/DivertorOptimization 아래에 저장한다. 과거 물리식·실행기·보고서를 덮어쓰지 않는다. 새로운 결과에 따라 숨은 튜닝, 조건 교체 또는 성공 정의 변경을 하지 않는다.

## 초기 집단 설정 정정 이력

이 규칙은 첫 방법의 부분 실행 뒤, 첫 방법 간 비교가 완료되기 전에 정정했다. 이전 population=12/projected_seeds=12 설정에서는 초기 집단이 바닥 투영 형상으로 모두 채워져 DE 집단의 0–11번 계수가 7세대/87회 호출까지 동일한 0이었다. 좌표 개선 제안은 일부 다른 좌표를 시험할 수 있으므로 모든 제안이 바닥에 한정됐다는 뜻은 아니다. 원래 생산 CLI의 기본값 population=64/projected_seeds=12를 사용해 기존 초기화 함수가 나머지 52개를 전 좌표 교란과 전체 경계 제안으로 채우도록 한다. 열유속 비교 결과를 근거로 매개변수를 조절하지 않았다. 이전 부분 실행은 별도 진단으로 보존하고 새 결과와 합치지 않는다.

최초 초기화에서 각 계수 범위가 1e-12 m보다 크고, 고정 계수 경계 폭으로 정규화한 중심화 초기 집단의 affine rank가 16인지 열점수 평가 전에 확인한다. 실패하면 재표집하지 않고 실패로 기록한다. 재시작의 초기 집단도 기록하되 기존 재시작 규칙을 바꾸지 않는다. 시간 지점별로 실제 완료된 초기집단 평가·DE 제안·좌표 개선 수, 평가된 벡터의 범위/차원, 기하 적격/실제 수송 계산에 들어간 범위를 별도로 보고한다. 저장된 초기 집단의 다양성을 시간 내 전체 집단 평가나 전 형상 공간 최적성으로 해석하지 않는다.
