# 중간면 반사 경계 수정과 재실행

첫 시드의 두 형상에서 FIREFLY가 각각 상부 물질벽에 36.553359 W를 침적했다. 반사면 흡수·영역 이탈·시간 검열은 모두 0 W였고 전력은 1 MW로 닫혔다. 원래 실행기의 상부벽 0.3 W 미만 검사에서 두 건 모두 탈락했다. 원본 두 NetCDF, 실행 코드, 실패 로그와 파일 지문을 별도로 보존했다. 두 결과의 형상 순위를 산출하기 전에 실행을 중단했다. [원래 실행 봉인](execution.json) · [첫 두 실패 기록](first-run-incident.json)

MPI rank 2의 열이력 763은 내부 자기 경계에서 자기좌표를 보정한 뒤, 갱신 전의 물리좌표로 다음 평행 스텝을 시작했다. 두 좌표가 가리키는 중간면 높이 차는 0.390 nm였다. 같은 난수에 대한 국소 재생에서 원래 구현은 반사면을 연달아 두 번 만나 남은 평행 변위를 상부로 보냈다(최종 Z = +0.65456 m). 내부 경계에서 물리좌표를 한 줄로 동기화하면 반사는 한 번이며 마지막 Z = −0.62822 m이다. [수정 패치](cap-sync.patch) · [궤적 재생 로그](cap-replay.log)

원래 라이브러리를 별도 경로에서 다시 빌드해 기존 기준 계산을 바이트 단위로 재현했다. 수정본도 두 번 빌드해 바이너리 해시가 일치했다. 수정한 열계산으로 기존 양의 토로이달 자기장 기준 1건과 이번 음의 자기장 사례 2건을 재생했으며 세 건의 상부벽 전력은 0 W였다. 난수 시드가 같아도 보정 뒤 후속 궤적과 국소 열분포는 변했다. 이 세 건은 경계 보정 확인용이다. [세 대조 계산의 정량 차이](cap-control-results.json) · [독립 빌드·진단 재현](native-repair.md)

재실행은 별도 연구 폴더 `nf-stage5-firefly-20261110-r2`에서 처음부터 276개 슬롯을 모두 계산한다. 시험할 가족, 고정 물질벽, 평형별 자기 격자, 원래 OMP 열원, 시드, 물리 계수, 1% 판정 규칙, 상부벽 검사는 최초 등록을 따른다. 원래 준비와 필드 검증에 쓴 라이브러리는 `ready.json`에 남기고, 실제 열계산이 불러온 수정 라이브러리는 네이티브 프로세스 메모리 매핑과 SHA-256으로 각 시드 영수증에 기록한다. 수정된 실행에서 동일한 검사를 통과한 결과만 주 비교에 넣는다.
