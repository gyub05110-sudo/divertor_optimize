# 선택 후보의 추가 수치 민감도 검사

앞선 두 평형의 진행 중 결과에서 A₂ 증가가 0.08%인 후보가 나와 이 검사를 추가한다. 이는 실시간 비교의 결과를 관찰한 뒤 정한 진단이다.

200초 실시간 비교 18회가 모두 끝난 뒤 각 방법이 마감 안에 채택한 형상 전부와 각 평형의 기준벽을 재평가한다. 중복 형상은 한 번만 계산한다. 후보 선택, 시드, 마감 및 원래 판정 결과는 이미 저장된 실시간 기록으로 고정한다.

대안 수치 설정은 기존 640경로 수준의 적분 스텝과 벽 이산화에 quintic 자기장 보간을 결합한 하나의 설정이다. 원래 실시간 결과인 cubic1280과 동일 물리식·동일 입력을 사용하며, 해상도와 보간을 동시에 바꾸는 민감도다. 연속체 오차상한 또는 국소 q 분포 수렴 인증에는 쓰지 않는다.

각 설정 자체의 기준벽 대비 피크 및 A₂ 변화의 부호와 크기를 기록한다. 추가 설정에서의 적격성과 전력수지, 각 후보의 CPU/GPU 피크·면적 일치를 확인한다. 통과 기준을 맞추려고 후보, 입력 또는 원래 마감 결과를 교체하지 않는다. 이 검사 비용은 사후 검증 비용으로 따로 기록한다.
