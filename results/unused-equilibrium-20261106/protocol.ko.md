# 미사용 DIII-D 방전의 동일 시간 비교

검증 목적은 각 입력 평형에서 원래 DIII-D 물질 벽을 출발점으로 탐색한 후보의 피크 감소와 정밀 탐색에 대한 고속 선별의 이득이다. 원형 벽의 열유속이 각 평형의 비교 기준이다. A₂ 증가 여부를 별도로 기록한다.

## 자료와 계산 전 고정 규칙

- 공개 Sophelio/fusion-equilibrium-challenge 데이터셋 revision 1e280905b85f2a6fdde7e06fca8cf3a1edf447cb의 diii_d_train 원파일 목록을 쓴다. 공개 시험 세트에는 EFIT 정답이 없으므로 선택 대상에서 제외한다. CC-BY-4.0 출처를 기록한다.
- 과거 사용한 익명 식별자 1a3155370c를 제외한다. 전체 경로에 문자열 unused-equilibrium-20261106/를 앞붙여 SHA-256한 오름차순의 첫 12개를 조사 대상으로 고정한다. 선택은 열유속, 성공 여부, 기존 형상 점수를 읽기 전에 한다.
- 각 자료에서는 1,400 ms에 가장 가까운 저장 시각 하나를 선택한다. 동률이면 이른 시각이다. 100 ms 이상 떨어지면 탈락으로 기록한다. 시간 또는 방전을 유리한 열 결과로 교체하지 않는다.
- 원래 입력과 자기장 배열을 비교해 중복 방전 또는 동일 평형이면 제외한다. 실제 방전 번호가 익명화된 경우 방전 구별은 공개 자료 식별자와 배열 지문에 따른다.
- 고정 DIII-D 물질 벽, OMP 변형구간, 기하 제약과 기존 방향·단위 규약을 사용한다. 두 적분 스텝에서 하부 양쪽 최초 충돌면을 확인하고 원래 코드의 안쪽 사면 조건과 OMP 끝점 일치를 요구한다. 이 조건을 통과한 첫 세 평형을 고른다. 모든 조사 대상의 제외 이유를 남긴다. 기하 전처리에 열점수를 사용하지 않는다.
- 전력 1 MW, 밀도 1e19 m^-3, χ⊥ 0.3 m²/s, λq 3 mm, γ 7, κ0 2000, OMP 단독 열원, 최소 곡률반경 20 mm로 고정한다.
- 시드는 20611, 20627, 20639이다. 두 방법은 동일 시드의 기하 제안 순서와 후보 제약을 쓴다. 후보는 12개, 제안 시도 최대 600번이다. 고속 방법은 적격 후보 네 개 묶음을 저비용 점수로 선별해 한 개를 정밀 평가한다. 직접 방법은 차례대로 정밀 평가한다.
- 시간 예산은 프로세스 시작부터 200초다. 임포트, 준비, 후보 생성과 탈락, GPU 초기화, 최종 정밀 확인을 포함한다. 200초를 넘겨 끝난 계산은 결과 채택에서 제외하며 소요시간을 기록한다. 각 프로세스는 자기 전용 빈 CUDA/CuPy 디스크 캐시를 D에서 사용한다. 시험은 직렬 실행한다. 각 평형·시드의 실행 순서는 인덱스 짝홀에 따라 교차한다.
- 기존 cubic320/cubic1280 설정과 계산식을 사용한다. 준비 중 부적격·오류·시간초과도 결과로 기록한다. 한쪽 실패가 다른쪽 실행을 막지 않는다. 기하 통과 이후의 열계산 실패를 이유로 다른 방전으로 교체하지 않는다.
- 1차 지표는 시간 내 정밀 확인한 최선과 같은 평형 기준벽의 피크 비율이다. 두 방법 사이 상대 피크, A₂ 변화, 5% 피크 감소를 처음 정밀 확인한 시간, 정밀/저비용 계산 수, 채택 가능 결과 유무를 함께 기록한다. 양 방법이 생성한 공통 후보 접두사의 ID와 시도 번호를 확인한다.
- 명목 동률은 숫자 그대로 기록하고 0.1%·1% 이내 차이 여부도 표시한다. 단일 방전/시드 관측 수를 독립 방전 표본 수로 부풀리지 않는다. 물리적 실제 q(s) 검증과 FIREFLY 검증은 이 실험에 포함하지 않는다.
- 원파일, 변환 입력, 로그, 프로파일, 임시·GPU 캐시와 결과는 D:/DivertorOptimization 아래에 저장한다. 저장소의 기존 입력을 덮어쓰지 않는다.

## 구현과 검산

1. 입력 목록과 다운로드 SHA-256, 고정 원본 벽·코드 해시를 저장한다.
2. 기존 nf_equilibrium_times의 기하 규칙으로 평형별 입력 root를 생성한다. 원자료 배열을 변경하지 않는다.
3. nf_base_live.run_arm을 재사용하는 별도 감독 프로세스에서 각 자식의 root와 시드를 지정한다. 기존 생산 코드와 역사 실행 코드는 보존한다.
4. 실제 실행 전에 마감·실패 처리·공통 접두사를 검증하는 기존 테스트와 신규 감독 코드의 필요한 회귀 테스트를 실행한다.
5. 실시간 기록에서 최종 채택 후보와 마감 준수를 별도 감사하고, 각 평형과 시드의 결과를 모두 표로 작성한다.
