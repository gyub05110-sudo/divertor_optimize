# 최종 후보 재검증 및 선택적 peak 구간 축소

2026-11-03. 기준 커밋 `065ff90380e92e85d1b84b73a89f8daef442bec1`, 작업 브랜치 `codex/selective-candidate-validation`.

## 판단

빠른 형상 탐색은 기존 경로로 유지하고, 추가 구간 검증은 소수 최종 후보에만 적용하는 구성을 구현했다. 저장 후보의 수치적 개선을 재확인했고, 고정된 donor 분포의 공간 peak 비교와 연속 경로 구간 축소를 별도로 측정했다. **연속 경로 검증을 모든 탐색 평가에 적용할 성능은 아직 확보하지 못했다.** 따라서 새 검증기는 기본 탐색에 자동 연결하지 않는다. 전역 최적성 인증도 필수 단계로 추가하지 않는다.

이번 작업은 새 형상 탐색이나 새로운 최저 peak 발견이 아니다. 기존 후보를 같은 현재 정책으로 재검증하고, 후보 비교에 필요한 검증 수단의 효용과 비용을 측정한 결과다.

## 같은 조건에서의 후보 재검증

고정된 DIII-D 기준 형상·자기장·운전 입력을 사용했다. IMP와 OMP는 각각 독립적인 1 MW 실험이다. 입력 밀도 1e19 m⁻³, 횡방향 확산계수 0.3 m²/s, λq 3 mm, γ 7, κ₀ 2000을 유지했다. 각 source/resolution의 기준 평가와 경로 준비를 공유했다.

|---|---:|---:|---|
| IMP 기준 | 2.5496630284 | — | 통과 |
| IMP 20 mm | 2.3751842312 | 6.8432% | 통과 |
| IMP 50 mm | 2.4815540599 | 2.6713% | 통과 |
| OMP 기준 | 2.7307561171 | — | 통과 |
| 캠페인 OMP 50 mm | 3.0038680600 | −10.0013% | 통과하나 개선 아님 |
| 과거 OMP 50 mm | 1.9958528551 | 26.9121% | 통과 |

320/640/1280 donor, cubic/quintic 보간, 벽 격자 세분화, 현재 전체 벽 형상 검사와 독립 열·전력 검사를 적용했다. 후보와 기준의 unhit/unresolved power는 0, 선택 후보의 최대 전력수지 오차는 약 1.55e-15였다. 이번 재검증 대상에는 과거 OMP 20 mm 후보를 포함하지 않았다. 전체 벽 검사에서 탈락한 것은 72시간 캠페인의 별도 OMP20 후보(식별자 `2cf53582…`, coarse peak 약 1.439753 MW/m²)다. 이전 접선·곡률 연구의 OMP20 후보(`748b4cbc…`, 당시 refined peak 1.446258 MW/m²)는 현재 형상 검사도 통과하며, 이번 정책의 전체 열수송 재검증은 아직 수행하지 않았다. 기존 결과 저장소에 후보를 자동 승격하거나 덮어쓰지 않았다.

2026-11-03 정정: 최초 보고서의 “과거 OMP 20 mm의 낮은 값은 후속 전체 벽 검사에서 탈락”이라는 문장은 서로 다른 후보를 혼동했다. 원본 계수와 식별자를 대조하고 열계산 없는 형상 재검사를 수행해 위와 같이 바로잡았다. [판정 추적 기록](../omp-rejection-audit-20261103/REPORT.ko.md)을 참조한다.

전체 재검증은 1,190.65초였다. 준비 554.79초(기준 평가 172.17초 포함), 후보 평가 370.58초, 후보 audit 176.64초, 기준 audit 79.54초다. CPU 작업이 함께 실행된 세션의 관측값이며, 독립된 성능 비교나 가속률로 해석하지 않는다.

## 공간 peak 판정의 범위

`selective_peak.py`는 donor 도착 위치를 사용해 공간을 나누고 peak 상·하한을 유지한다. 좁은 폭의 image bound와 넓은 폭의 Fourier bound를 연결하며, 폭 범위가 두 영역에 걸치면 두 경우를 모두 포함한다. 전력이나 모호한 분기를 버리지 않는다. 시간·분할 예산이 끝나면 유효한 구간을 반환하며 겹치는 후보는 `unresolved`로 남긴다. 모델·기준·source·resolution 식별자와 독립 replay를 확인한 뒤 비교한다.

320 및 1280 donor 실험은 기준 형상 8초, 각 후보 30초의 동일한 생성 예산을 사용했다. replay와 파일 입출력은 별도 비용이며 전체 소요시간에 포함한다. 결과와 판정은 [comparison_summary.json](comparison_summary.json)에 기록한다. 320 donor에서 IMP 20/50 mm 및 과거 OMP 50 mm의 상한이 기준 하한보다 낮아 개선을 판별했다. 생성·독립 replay를 포함한 전체 비교는 380.89초였다. 반면 1280 donor에서는 351.65초를 사용했으나 다섯 비교가 모두 `unresolved`였다. 더 적은 분할만 완료했으므로 이 짧은 전체 시간을 성능 개선으로 해석하지 않는다.

320 donor의 IMP 기준 구간은 [2.549178, 3.365830], IMP20은 [2.375044, 2.399681], IMP50은 [2.481368, 2.536365]였다. OMP 기준은 [2.729558, 3.347541], 과거 OMP50은 [1.996209, 2.114703]였다. 캠페인 OMP50 대 기준의 구간 비교는 320에서도 미해결이다. 수치 재검증에서 관측한 악화와 구간으로 인증한 판정을 구분한다.

이 판정은 **수치 계산으로 고정한 위치·폭·전력의 유한 Gaussian donor 모델**에 대한 것이다. 연속 자기장 경로의 수치 오차, 연속 source 적분 오차, 형상 전역 최적성까지 증명한 결과가 아니다. 해상도 재검증과 고정 커널 인증을 혼동하지 않는다.

## 연속 경로 구간 축소

기존 연속 경로 연구의 16 donor 모델을 재사용해 같은 후보의 정확한 한 형상에서 비교했다. 첫 단계는 상관관계를 덜 잃는 spline 구간 계산과 이미 증명된 Picard tube의 교집합 축소다. 다음 단계는 도착 후보 구간과 누적 적분 폭 기여가 큰 구간만 세분화한다. 처음부터 원래 source에서 다시 검증하고 원래 분기와 모든 donor를 유지한다. 기존 `legacy` 모드와 replay는 그대로 유지한다.

| source | 초기 공간 peak 구간 | 축소 후 구간 [MW/m²] | 초기 cache replay | refinement 실제/예산 | 최종 replay |
|---|---|---|---:|---:|---:|
| IMP | [0.013506, 106.491814] | [0.013506, 32.065264] | 192.54 s | 186.64 / 150 s | 8.59 s |
| OMP | [0.013501, 207.637219] | [0.013501, 87.322060] | 204.62 s | 156.20 / 150 s | 8.96 s |

초기 진단은 source당 약 21.8~21.9초, 두 source 전체는 804.59초였다. IMP 4회, OMP 3회의 donor 교체를 채택했다. 이 예산에서는 첫 단계만 실행되어, 실제 구간 세분화는 별도 단일 donor 실험으로 확인했다. 구간 축소는 peak 자체의 개선이 아니며, 현재 구간은 후보 우열 판정에 여전히 넓다.

별도 IMP donor 2 실험에서는 가능한 hit 122–124 주변과 큰 적분 기여 구간 중 24개를 선택했다. 153→225 cells, 같은 source·분기·정확한 끝점에서 길이 구간 폭 12.939688→7.668918(40.73% 축소), 적분 구간 폭 13.622165→8.343070(38.75% 축소)를 얻었다. trace 20.77초, replay 20.38초, 독립 수치 audit 0.64초, 전체 43.14초였다. replay 및 독립 DOP853 4,275개 검사를 통과했다. 이 단일 경로 실험을 전체 peak 개선으로 환산하지 않는다.

예산 검사는 비중단 연산 사이에서 수행한다. 마지막 한 round 때문에 IMP 36.64초, OMP 6.20초 초과했다. 초기 cache replay·진단·마지막 replay는 150초 refinement 예산 밖이다. 엄격한 전체 실행 마감시간을 보장하지 않는다.

## 재현성과 수정 사항

- 재검증의 역사적 입력 934개가 변경되지 않았다. 원래 실행의 넓은 코드 감시에는 동시에 수정한 **사용하지 않는** 연속 경로 모듈 2개도 포함돼 종료 코드 1을 기록했다. 이 실패 기록을 수정하지 않았다. 별도 `code_scope_audit.json`이 원래 summary/index 해시에 결합되어, 소비된 42개 모듈의 전후·스냅샷 바이트 일치와 두 변경 모듈의 미사용을 검증한다. 누락된 간접 import 3개는 해시로 보호된 과거 스냅샷의 동일 바이트로 보충했다. 이는 실행 당시 import telemetry가 아닌 보존 코드의 fresh import와 정적 참조 검사로 재구성한 증거라는 한계가 있다. 비교기는 명시적 audit 없이 원래 실패한 코드 감시를 수락하지 않는다. 앞으로의 runner는 실제 import한 의존성을 보존한다.
- 연속 경로 본 실행은 수정 전 snapshot으로 실행됐다. 원래 보호 수는 151이며, 후속 독립 audit은 이전 연구의 상속 입력까지 합쳐 1,345개 파일을 확인했다. 원래 `atomic_round_seconds`에 평가 시간이 빠진 항목은 보존하고 `execution_audit.json`에 설명했다. 본 표는 전체 `refinement_seconds`를 사용한다. 현재 코드에서는 해당 측정 누락과 상속 입력 hash 검사도 수정했다.
- 구간 세분화 첫 시험에서 긴 정확 소수 끝점이 반올림되는 문제를 발견했다. 원래 chart의 끝 평면을 그대로 보존하고 끝점 불일치 시 거부하도록 수정했다. 실패 기록을 보존한 뒤 `fixed/`에서 다시 실행해 위 결과를 얻었다.
- 기존 117개 회귀검사와 신규 검사를 포함해 172개 테스트를 통과했다. 공간 peak·연속 경로·후보 재검증·입력 수락 규칙에 대한 독립 코드 리뷰를 수행했다. 빠른 최적화 평가기와 탐색 루프는 변경하지 않았다.

## 다음 작업과 채택 기준

1. 수치 재검증을 통과한 IMP20과 과거 OMP50을 다음 빠른 탐색의 비교 후보로 사용한다. 곡률 50 mm가 필요한 IMP 실험에서는 IMP50을 별도로 유지한다. 새 목표나 입력으로 실행할 때는 그 조건의 기준 형상을 다시 평가한다.
2. 최종 후보 비교에서 기준 lower bound와 후보 upper bound의 겹침에 따라 예산을 배분하고, 우열이 판별되면 조기 종료한다. 후보별 고정 30초는 이번 측정용 설정이다. 독립 replay 캐시를 같은 해시에 한해 재사용할 여지도 측정한다.
3. 높은 해상도에는 위 후보들만 올리고, 같은 정확도에서 준비·평가·refinement·replay를 합한 총 시간과 첫 유효 개선까지 걸린 시간을 기존 방식과 비교한다. 이번 결과만으로 탐색 가속을 주장하지 않는다.
4. 연속 경로 검증은 비용 대비 감소량이 큰 donor에 한정한 연구 옵션으로 유지한다. geometry box 전체 및 ±100 mm 전역 인증은 최종 후보의 우열 판정이 실용적인 시간에 가능해진 뒤 확장한다.
