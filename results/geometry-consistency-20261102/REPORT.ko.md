- 새 campaign snapshot은 --warm-study 및 저장소 results의 검증 후보를 일반 coarse warm seed와 별도로 동결한다. manifest가 아직 없더라도 완성 qualified 묶음에서 후보를 찾는다. 이전 검증 결과는 좌표·출처 해시로 가져오며 현재 입력·정책의 검증을 생략하지 않는다.

- 요약·그림은 편의 출력 경로 대신 해시가 확인된 보존 묶음을 읽는다. 이전 형식의 연구 결과도 읽을 수 있다.

## 검증 범위

52개 회귀 테스트 통과: 실제 저장 형상 충돌 재현, 열계산 전 차단, 열격자 변경과 무관한 형상 판정, 원본 유효 형상 유지, 나쁜 후보의 덮어쓰기 방지, 저장 중단·재시작, 해시 손상, 입력·후보·정책 불일치, 오래된 검증 캐시 무효화, snapshot에 보호 후보 동결, 새 엄격 조건 후보의 느슨한 조건 전파, 요약의 보존 묶음 선택을 포함한다. 열계산 및 promotion 통합 테스트에는 작은 합성 결과를 사용했으며 실제 열수송을 다시 계산하지 않았다.

네 저장 형상에서 공통 검사 중앙 시간은 약 2.4–3.6 ms, 기존 검사 대비 추가 약 0.3–1.5 ms였다. 전체 최적화 속도 측정은 아니다. 원본 26개 결과 파일과 실행 snapshot 874개 파일 해시가 유지되었다. geometry_regression.json에 형상 검사와 시간·출처를 기록했다. 이전 pilot OMP50의 약 1.995853 MW/m² 후보도 현재 형상 검사를 통과하지만, 이번 작업에서 새 입력/정책의 열수송 정밀 검증을 수행한 것은 아니다.

이번에는 코드와 저장·선택 절차를 보완했다. 새 최적화와 열수송 계산은 시작하지 않았고 기존 72시간 연구의 수치나 시한은 바꾸지 않았다. 향후 실행은 새 출력 폴더에서 새 snapshot을 만들고 필요한 이전 연구를 --warm-study로 지정한다. 이 코드를 만료된 연구 snapshot에 복사해 재개하면 안 된다.

검사는 유한 chord 오차의 수치적 형상 판정이며 연속곡선의 엄밀한 충돌 부재 증명은 아니다. 영구 보존은 이 저장소/연구 폴더에서 자동 순위 교체·중단으로 잃지 않는다는 뜻이며 별도 디스크 백업을 대신하지 않는다.

## 전역 최적성을 증명하려면

현재 IMP는 9개 변수, OMP는 16개 변수를 사용한다. 형상 계열·변수 범위·접선·곡률·개구부·입력·수송 모델과 peak 정의를 먼저 고정해야 한다. 모든 가능한 divertor 형상이 아니라 이 명시된 문제의 최적성을 다룬다.

최소화 문제의 실제 최적값 f*에 대해 L <= f* <= U를 만들어야 한다. U는 제약이 확인된 후보의 목적함수 상한이고, L은 미탐색 영역을 포함한 전체 허용영역의 하한이다. U-L <= epsilon을 확인하면 절대오차 epsilon 이내 전역 최적성을 인증한다. 양의 peak에서는 U <= 1.01 L을 만족하면 전역 최적값 대비 1% 이내라고 주장할 수 있다. 1%는 예시 연구 목표이며 현재 달성했다는 의미가 아니다.

공간 branch-and-bound는 변수 구간을 나누고 각 구간의 유효 하한을 계산해 개선이 불가능한 구간을 제외한다. 엄밀한 수치 증명에는 interval arithmetic 등으로 반올림과 평가 오차도 포함해야 한다. 근거: [Gurobi nonlinear optimization 설명](https://docs.gurobi.com/projects/optimizer/en/current/features/nonlinear.html), [Neumaier의 complete global optimization 논문](https://optimization-online.org/wp-content/uploads/2003/10/765.pdf).

우리 계산에서는 첫 충돌 면 전환, 자기장선 적분, 열전도·sheath 해, Gaussian 확산과 연속 벽 peak 계산을 모두 포함하는 하한/오차 경계가 필요하다. 현재의 샘플 격자 수렴과 장부 보존만으로는 이 경계를 얻을 수 없다. 기존 verification/global_certificate_geometry.py와 certify_fixed_model.py의 특정 frozen-polyline 기하 배제 증명 역시 현재 열수송·G1 형상 최적화의 전역 최적성 증명이 아니다.

빠른 형상 최적화라는 목적에는, 현재 탐색으로 좋은 상한 U를 확보하고 별도 인증 모듈에서 하한 L을 좁히는 구조가 적합하다. 우선 작은 변수 부분문제의 epsilon 인증을 시험하고, 경계의 조임과 비용이 확인되면 전체 9/16변수로 확장하는 순서를 권한다. 작은 부분문제의 증명을 전체 문제의 증명으로 표현하면 안 된다. 대리모델을 사용한다면 전 영역에서의 대리모델 오차 경계도 필요하다. 여러 시작점·GPU 장시간 탐색·반복 수렴은 탐색 근거를 강화하지만 하한 인증을 대체하지 않는다.
