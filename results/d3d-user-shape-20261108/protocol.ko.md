# 단순 바닥 형상의 피크 감소 시험 설계

두 파일 모두 이전에 열결과를 확인한 개발 사례다. 이 문서는 아래 짝지은 탐색과 고정 형상 재평가를 시작하기 전에 비교를 고정한다.

| 식별자 | 입력 parquet SHA-256 | 시각 | 실행 순서 |
|---|---|---:|---|
| e806f47778 | `dc0eba5720dc0a8b9894ae6fdaf5f346b4d5b2a06ca4d40cd83be8def591f0a5` | 1400 ms | full → floor-only |
| 1a3155370c | `cae74032203593dfc1e8d9b7571785a3b3ad558f6e4265e938a33f16e422022c` | 1400 ms | floor-only → full |

1. **동일 시간 탐색.** 각 평형에서 16계수 `full`과 바닥 4계수 `floor-only`를 각 360초, 같은 시드 20711로 별도 프로세스에서 순차 실행한다. 기본 DIII-D 벽·정책·기준 전력 1 MW·λq 3 mm·χ⊥ 0.3 m²/s·밀도 10¹⁹ m⁻³·곡률반경 하한 20 mm, GPU 밀도 합산, cubic320 선별과 cubic1280 채택을 사용한다. 이전 형상이나 다른 실행의 열계산을 읽지 않는다. 공용 커널 컴파일 캐시는 유지한다. 시한에 늦은 후보와 준비 비용을 기록한다. 적격 정밀 후보가 없으면 해당 짝은 미판정으로 보존한다.
2. **같은 효과의 판정.** 우선 각 승자의 원벽 대비 피크 변화율을 구한다. 두 승자가 모두 원벽을 개선하고 각 공통 수치 설정에서 제약을 통과할 때, `100*(q_floor/q_full−1)`가 모든 설정에서 ±1% 이내면 이 실험에서 동급으로 부른다. 바닥이 모든 설정에서 1% 넘게 낮으면 바닥 우세, 모든 설정에서 1% 넘게 높으면 전체 형상 우세다. 혼재하면 범위로 보고한다. 이 1%는 연구용 실용 차이이며 제작 허용오차·통계적 동등성 한계와 별개다. 최소화 순위에는 반올림·1% 동률·A₂ 가중치를 적용하지 않는다.
3. **고정 형상 대조.** 각 승자의 정확한 계수를 보관해 cubic1280, quintic1280, cubic640에서 재평가한다. 각각 같은 설정으로 원벽도 계산한다. 전체 승자의 입구·선반·연결부 계수 12개만 0으로 만들어 바닥을 고정한 직접 대조를 더한다. 전체 승자가 바닥만 움직였다면 같은 형상임을 표시하고, 비바닥 계수가 있는 최저 적격 전체 후보와 그 바닥만 남긴 대조를 가능한 경우 추가한다. 스플라인 전체 제약과 열평가는 그대로 유지한다.
4. **더 단순한 형상.** 바닥의 자유 계수 네 개를 모두 같은 값 `a`로 묶은 1변수 계열에서 −40, −20, 0, +20, +40 mm를 미리 고정한다. `a=0`은 원벽에서 의무 G1 접합만 맞춘 0변수 형상이다. 접합·개구·곡률 등의 조건을 위반한 값은 탈락 사유와 함께 남긴다. 각 고정 형상이 원벽 대비 얼마나 개선하며 전체 승자에 얼마나 근접하는지 위와 같은 정의로 비교한다. 시간 기반 승자와 사후에 추가 계산한 이산 패널의 비용은 각각 표기한다. 양쪽의 공통 투영 초기 형상, 시간 내 정밀 계산된 독립 재시작 후보도 기록한다.
5. **산출물과 해석.** 후보 ID·계수·거리·시간과 함께 첫 도달 전력, 침적 전력, 공통 물질 좌표의 q(s), 열점, A₂, 경로 길이와 폭, 선반 각도·전력수지를 기록한다. 초점은 제한 시간의 설계와 배치 효과다. 두 이미 알려진 평형·각 한 시드를 일반화 성능, 전역 최적성 또는 FIREFLY에서의 우위로 외삽할 수 없다. 미사용 평형 벤치마크와 새 FIREFLY 계산은 이 시험 범위 이후다.
