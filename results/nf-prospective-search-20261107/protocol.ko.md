# 새 DIII-D 평형에서의 동일 시간 형상 탐색 검증 규칙

연구 질문은 주어진 평형·열원·수송계수에서 고속 탐색이 허용 시간에 확보하는 형상의 품질이다. 주 평가값은 적격 후보의 정밀 표적 피크이며, 분포의 유효면적 A₂, 피크·면적 동시 개선과 전력수지를 함께 본다. 같은 평형에 제공된 DIII-D 원벽을 기준으로 쓴다. OMP 1 MW, n=10¹⁹ m⁻³, χ⊥=0.3 m²/s, λq=3 mm, γ=7, κ₀=2000, 최소 곡률반경 20 mm, 기존 기하 제약과 OMP 16개 변수를 고정한다. FIREFLY는 별도 물리 교차검증으로 사용한 선행 근거다.

## 개발용 대조군 선택

이전 600초 연구의 아홉 정밀 실행에서 초기 집단 평가 요청 504건과 좌표 개선 요청 23건이 완료됐고, 완료된 차분진화(DE) trial은 0건이었다. 이번에는 이미 결과를 본 세 평형 deb842cf1e, fad1624516, 4d14a35fcb의 시드 20611에서 정밀 탐색 설정 두 가지를 각각 600초 실행한다. 초기 집단 크기/투영 시드 수는 24/8과 32/12다. 각 실행은 빈 캐시와 새 프로세스에서 출발한다. 초기 집단은 16개 축 모두 범위가 10⁻¹² m보다 크고, 고정 변수 폭 0.2 m로 정규화한 중심화 행렬의 rank가 16이어야 한다. 현재 실행에서 처음 만든 모든 초기 벡터와 특이값을 기록한다.

설정이 선택 대상이 되려면 세 개발 실행이 정상 종료되고 rank 검사를 통과하며 최소 두 평형에서 600초 안에 실제 침적을 계산한 새 적격 DE trial이 하나 이상 있어야 한다. 같은 형상의 캐시 조회와 계산 전 기하 탈락은 이 수에서 제외한다. 선택 대상 중 세 평형의 최종 피크/해당 원벽 피크 기하평균이 가장 작은 설정을 선택한다. 정확한 동률은 적격 DE를 완료한 평형 수, 그 뒤 작은 집단 크기 순으로 판정한다. 두 설정 모두 조건에 미달하면 개발 결과와 원인을 보존하고 새 평형의 열결과를 열기 전에 대조군 설계를 재검토한다. 선택 근거와 여섯 실행 해시를 봉인한다.

## 전향 시험

고정한 공개 데이터 revision과 해시 순서, 사전 지정한 시각·기하 규칙을 적용해 이전 연구에서 열평가하지 않은 익명 DIII-D 입력 세 개를 정한다. 원자료 12개와 원래 입력을 포함한 기사용 식별자 및 동일 평형 프레임을 검사한다. 입력 목록·제외·선택 이력, 각 평형/원벽 파일과 개발 선택 기록을 첫 전향 열계산 전에 봉인한다. 등록 후 열계산이 실패하면 해당 평형과 시드의 실패를 결과에 포함한다.

각 새 평형의 고정 시드는 20711, 20729, 20747이다. 두 방법은 기존 고속 선별(64/12, cubic320의 적격 새 후보 네 개마다 하나를 cubic1280에서 확인)과 개발 단계에서 정한 직접 정밀 탐색(cubic1280)이다. 두 방법 모두 원벽에서 시작한다. 실행마다 새 프로세스와 빈 전용 D 캐시를 쓰고 단일 RTX 3090에서 직렬 계산한다. 방법 순서는 평형 순번과 시드 순번 합의 홀짝으로 교차한다. 전향 시험은 총 18회다.

주 비교는 모든 9쌍의 600초다. 200/400초에 같은 경로에서 확인된 정밀 후보도 보고한다. 평형별 첫 시드 20711은 양 방법 모두 1800초까지 계속해 세 쌍의 긴 예산 비교를 얻는다. 나머지 두 시드는 600초에서 마감한다. 600초까지 관측한 결과의 선택 규칙은 양 실행 길이에서 같다. 시한은 부모가 자식 프로세스를 시작하는 시각부터 재며 임포트, 원벽·자기선 준비, GPU 초기화, 제약 탈락·점수·첫 CPU 대조와 실행 중 기록을 포함한다. 입력 취득과 기하 사전 검사, 부모의 해시 확인·빈 캐시 생성, 종료 직렬화와 사후 수치 검증 비용은 따로 기록한다. OS 파일 캐시까지 비우는 절차는 없다.

## 지표와 판정

각 시점까지 완료된 새 적격 정밀 계산과 준비 완료한 기준벽 중 피크 최저를 채택한다. 제한 시간 이후 계산도 측정값·시각·적격성과 함께 보존한다. 각 평형/시드에서 G = 100 × (1 − 고속 피크 / 직접 정밀 피크)를 비교한다. G ≥ 1%는 고속 쪽 실용적 차이, G ≤ −1%는 직접 정밀 쪽 실용적 차이로 기록한다. 1%는 본 시험용 판정 폭이다. 원값·부호 및 0.5%·2% 기준도 함께 제시한다. 기준벽 대비 피크 감소, A₂ 변화·동시 개선, 최초 5% 피크 감소까지의 시간과 미도달, 정밀 단계의 적격 실제 DE trial 수를 각 쌍에서 보고한다. 기하 탈락, 시간 초과, 원벽 fallback, 노출된 적격 후보가 없던 실행을 보존한다.

각 평형에서 세 시드를 묶어 보며 독립 평형 수는 최대 세 개다. 모든 평형에서 고속 우세를 주장하려면 각 평형의 세 쌍 자료와 실용적 개선 폭을 충족한 중앙값이 필요하다. 조건을 충족한 평형의 수와 반례를 함께 보고한다. 실제 적격 DE가 완료된 쌍을 따로 세며, 대조군의 탐색이 제한된 경우 비교 범위를 명시한다. 1800초의 세 쌍은 별도로 판정한다.

추가 열계산에 앞서 각 평형 원벽, 양 방법의 모든 600초 최종 선택 및 1800초 최종 선택을 잠근다. 같은 물리식으로 cubic640/1280, quintic640/1280에서 재계산하여 native 피크·A₂·적격성 재현, 설정별 기준벽 개선 및 G의 범위와 피크 범위 분리를 확인한다. 유한 설정 범위를 기록하고 계산에 실패한 관측을 표시한다. 추가 계산이 시간 내 채택을 바꾸지 않는다. 이 단계가 입증하는 범위는 고정한 OMP 운전점과 입력·표본에 한정된다.
