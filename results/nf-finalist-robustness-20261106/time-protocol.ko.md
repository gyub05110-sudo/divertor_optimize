# 같은 DIII-D 벽의 다른 평형 시각에 대한 적용성 점검

1,400 ms 한 평형에만 작동한다는 반론을 검사한다. 저장된 시각 중 1,400 ms 앞뒤로 정확히 200 ms 떨어진 1,200과 1,600 ms를 계산 전에 고정한다. 두 시각 모두 같은 방전이며 독립 방전으로 보지 않는다. OMP만 조사한다.

기준 물질 벽, OMP 변형 가능 구간, 공학 제약과 1 MW 운전 입력은 그대로 둔다. X점과 양쪽 strike를 각 시각에 다시 계산하고 두 가지 경로 적분 스텝에서 결과를 확인한다. 기존 코드가 요구하는 69번 사면에서 안쪽 separatrix가 최초 충돌하고, 원래 기하 제약과 기준 열계산을 만족해야 한다. 다른 면에 도달하거나 원형 벽이 적격성을 잃으면 해당 시각을 '현 구현의 적용 범위 밖'으로 기록한다. 벽·각도 하한·운전 조건 변경, 실패한 시각 교체는 하지 않는다.

통과한 시각에서는 동결된 기존 OMP 첫 시드(5161)의 원형 벽 파생 후보 12개를 동일 순서로 평가한다. 새 평형에서 4개씩 묶어 cubic320 적격 최고 1개를 고른 다음에만 cubic1280 결과로 채점한다. 모든 12개도 cubic1280으로 평가한다. 각 시각에 원형 벽 유지까지 포함한 피크, 유효면적, 유한 집합 최저 대비 차이, G1 등 기하 적격성을 기록한다. 실제 200초 비교는 앞서 1,400 ms에서 시행한 별도 시험이다.
